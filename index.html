Como Criar Sua Primeira Página HTML

HTML é a linguagem usada para criar páginas da internet.

Passo 1 — Criar o arquivo

Abra o Bloco de Notas e salve um arquivo chamado: 

index.html

Passo 2 — Escrever o código

Copie este código: 

<!DOCTYPE html>
<html>
<head>
    <title>Minha Página</title>
</head>

<body>
    <h1>Olá Mundo</h1>
    <p>Minha primeira página HTML.</p>
</body>
</html>

Passo 3 — Abrir no navegador

Clique duas vezes no arquivo index.html.

O navegador abrirá sua página.

Explicando as Tags

  • <html> → inicia a página
  • <head> → configurações
  • <title> → título da aba
  • <body> → conteúdo visível
  • <h1> → título principal
  • <p> → parágrafo
Agora você já criou sua primeira página HTML 🎉
